# Tirth Suba

Mechatronics / mechanical engineering, building toward robotics. Also building with AI — multi-agent systems, applied ML, LLM tooling.

Currently: designing and building a 4-DOF desktop robotic arm from scratch — parametric CAD, 3D-printed structure, embedded motion control.

## Featured builds

**[robot-arm](https://github.com/tirthsuba15/robot-arm)** — 4-DOF desktop robotic arm + gripper. Parametric Fusion 360 CAD, 3D-printed (ABS) structure, ESP32 + PCA9685 servo control, `ikpy` inverse kinematics. Every joint documented with build sheets and design-decision logs.

**[SentinelActual](https://github.com/tirthsuba15/SentinelActual)** — Real-time multi-hazard disaster intelligence platform. Fuses live wildfire (NASA FIRMS) and seismic (USGS) data; an AI agent reasons over both and speaks ranked response actions.

**[nba-winprob](https://github.com/tirthsuba15/nba-winprob)** — Calibrated NBA win-probability model (XGBoost), leakage-free backtest, live win-probability curve.

**[heisenbug](https://github.com/tirthsuba15/heisenbug_plugin)** — Claude Code plugin that diagnoses flaky pytest tests via an 8-agent investigation pipeline. Names the suspect line, proposes the fix.
